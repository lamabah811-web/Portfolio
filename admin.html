Configuration requise

L'espace admin a besoin de Supabase pour enregistrer tes messages, projets et technologies.

  1. Crée un compte gratuit sur supabase.com puis un nouveau projet.
  2. Dans SQL Editor, colle le contenu de supabase/schema.sql (en remplaçant l'email admin par le tien) et clique sur Run.
  3. Dans Authentication → Users, clique sur Add user et crée ton compte avec ce même email.
  4. Dans Project Settings → API, copie l'URL et la clé anon public dans supabase-config.js.
